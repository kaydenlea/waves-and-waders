Mobile wrapper is not configured

This Capacitor app is configured to load the hosted Next.js site in a WebView, but server.url is not set.

Set MOBILE_SERVER_URL (recommended for local dev) or NEXT_PUBLIC_SITE_URL (recommended for production) and then run cap sync. 

# PowerShell example
$env:MOBILE_SERVER_URL="http://10.0.2.2:3000"
npm run cap:sync

See mobile/README.md for the full workflow.
